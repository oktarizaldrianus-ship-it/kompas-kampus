Tujuan dan Manfaat Kompas Kampus 2026

🎯 Tujuan Utama

Mengukur secara presisi faktor psikologis dan perilaku siswa SMA/SMK/MA dalam menentukan keputusan melanjutkan studi ke Perguruan Tinggi, serta memberikan instrumen asesmen modern berbasis digital bagi Guru BK.

💡 Manfaat Praktis

Membantu Guru BK memetakan kluster hambatan siswa secara cepat, mengotomatisasi laporan resmi sekolah berbentuk PDF, melakukan WhatsApp Blast intervensi, dan memberi data makro bagi pembuat kebijakan wilayah.

Blueprint TPB Extended & Formulasi 5 Profil Siswa

Kerangka kerja ini dikembangkan dari Theory of Planned Behavior (Ajzen, 1991) dengan perluasan variabel psikososial lokal. Rumusan matematis pembentukan kluster profil perilaku didasarkan pada skor komponen (skala 1 - 5):

🚀 1. Siap Meluncur

Kondisi: Niat (Niat > 3), Kendali Perilaku (PBC ≥ 3), dan Dukungan Sosial optimal. Siswa siap bertindak tanpa hambatan berarti.

💰 2. Pejuang Potensial

Kondisi: Niat tinggi (Niat > 3), namun terkendala finansial/jarak (PBC ≤ 3). Memerlukan intervensi beasiswa/KIP-K.

👨‍👩‍👧‍👦 3. Pejuang Restu

Kondisi: Niat bulat (Niat > 3), namun dukungan keluarga/orang terdekat rendah (Norma < 3). Memerlukan mediasi orang tua.

🔍 4. Pemilih Berkualitas

Kondisi: Sikap kritis sangat tinggi (Sikap > 4) dan kendali memadai (PBC > 3.5). Selektif terhadap kualitas kampus.

🌊 5. Masih Eksplorasi (Drifter)

Kondisi: Niat masih rendah atau ragu-ragu (Niat ≤ 3). Membutuhkan konseling karier intensif pemetaan minat bakat.

Logika Pemberian Rekomendasi (Behavioral Science)

  • Reduksi Gesekan (Friction Reduction): Bagi kluster Pejuang Potensial, sistem secara otomatis merekomendasikan panduan pendaftaran jalur KIP Kuliah guna memangkas persepsi kerumitan finansial.
  • Messenger Effect: Bagi kluster Pejuang Restu, pendekatan persuasif dilakukan dengan melibatkan figur otoritas terpercaya (Guru BK & Orang Tua) melalui forum dialog.
  • Salience & Deadline Reminders: Bagi kluster Siap Meluncur, intervensi difokuskan pada pengingat batas waktu pendaftaran (deadline) agar tidak terjadi penundaan (procrastination).

Workflow Sistem (Dari Isian Siswa hingga WA Blast & Laporan BK)

📝
1. Isian Siswa

Siswa mengisi data pribadi, pilihan kampus, cita-cita, serta skala sikap TPB di halaman Isian Siswa.

🧠
2. Analisis Algoritma

Sistem otomatis mengkategorikan siswa ke dalam 5 kluster profil psikologis & memvalidasi catch item.

🚀
3. WA Blast Massal

Guru BK di Dashboard dapat mengirim pesan bimbingan personal/massal via WhatsApp Gateway terpilih.

📊
4. Rekap Laporan BK

Guru BK mencetak laporan PDF resmi sekolah yang memuat rekap detail seluruh siswa & catatan kualitatif.

Alternatif WhatsApp Gateway (Resmi & Gratis/Freemium)

Untuk mengirimkan pesan bimbingan secara massal (Sniper Mode), sistem mendukung beberapa API Gateway populer:

1. Fonnte API

Penyedia gateway WA populer di Indonesia dengan kuota uji coba gratis (freemium) dan kemudahan integrasi token.

2. Wablas API

Layanan multi-device server WhatsApp berkecepatan tinggi dengan fitur pengiriman terjadwal dan webhook instan.

3. Baileys / WPPConnect (Self-Hosted)

Library Node.js open-source 100% gratis tanpa batasan kuota bulanan, di-host mandiri pada server sekolah/dinas.

Rekomendasi Pengembangan oleh Asosiasi ABKIN Wilayah

Apabila platform Kompas Kampus diadopsi dan dikembangkan secara resmi oleh pengurus ABKIN Wilayah (Asosiasi Bimbingan dan Konseling Indonesia), berikut adalah rekomendasi strategis skala makro:

  • 1. Integrasi Database Provinsi / Kabupaten: Membangun server terpusat berbasis Cloud (Firebase/PostgreSQL) yang menghubungkan seluruh satuan pendidikan SMA/SMK/MA se-provinsi untuk memonitor APK (Angka Partisipasi Kasar) secara real-time.
  • 2. Standarisasi Layanan Bimbingan Karir Berbasis Bukti (Evidence-Based Guidance): Menjadikan instrumen TPB ini sebagai asesmen wajib tahunan bagi seluruh konselor sekolah anggota ABKIN guna menyamakan standar layanan penyiapan studi lanjut.
  • 3. Kolaborasi Strategis Lintas Kampus (University Expo Collaborative): Memanfaatkan data ranking kampus tujuan pada dashboard admin untuk mengundang perguruan tinggi terfavorit dalam pameran pendidikan daerah secara tepat sasaran.
  • 4. Pelatihan Sertifikasi Konselor Digital: Mengadakan program pelatihan bagi Guru BK dalam mengoperasikan Sniper Mode WhatsApp Gateway dan analisis data psikometrik perilaku siswa.

Rekomendasi Arsitektur Sistem Skala ABKIN Provinsi

Untuk mengakomodasi puluhan ribu siswa SMA/SMK/MA se-wilayah, arsitektur sistem dirancang handal:

Frontend

HTML5, Tailwind/Bootstrap, Chart.js, Responsive Mobile-First.

Backend

Node.js Express / Firebase Cloud Functions untuk REST API.

Database

Firebase Firestore / PostgreSQL terstruktur multi-tenant per sekolah.

Hosting & Gateway

Vercel/Cloudflare + Fonnte/Wablas API untuk pengiriman WhatsApp massal.

Tentang Kompas Kampus 2026

Kompas Kampus adalah alat diagnosa kesiapan kuliah saintifik yang dikembangkan oleh Psychosophia Behavioral Lab, Program Studi Psikologi Islam bekerja sama dengan Prodi Bimbingan dan Konseling Pendidikan Islam (BKPI) IAIN SAS Bangka Belitung.

Alat ini diadaptasi dari Theory of Planned Behavior (TPB) oleh Icek Ajzen (1991).
